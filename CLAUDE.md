# Nexus DNS — контекст для Claude

Свой DNS на зарубежном VPS: режет рекламу (особенно в мобильных играх) и пускает Gemini/ChatGPT/
Claude из РФ через SNI-прокси. Пока для семьи и друзей владельца, дальше — функция Nexus (VPN-сервис,
репо Rklm-it/vgx3d). Устройство и сценарии — в `README.md`.

- AdGuard Home (DNS, профили, ClientID) + nginx stream (SNI на 443). Утилита `nexusdns/` — только stdlib:
  на сервере ничего, кроме python3, не ставим.
- `install.sh` — установка и обновление (идемпотентен). `nexus-dns apply` — состояние из `lists/`.
- Тесты: `pip install -e ".[dev]" && pytest -q`. Тест nginx `-t` идёт, если nginx установлен.
- Пользователь пишет по-русски — отвечать, комментировать и логировать по-русски.

## Инварианты

Каждое правило проверено на живом AdGuard Home v0.107.79 и nginx 1.24, а не взято из документации.

1. На негодный сертификат `tls/configure` отвечает **200 и ничего не применяет**: причина есть только в
   `warning_validation`. Проверять `valid_pair` в ответе (`apply.configure_tls`).
2. Список прокси — один источник для правил AdGuard Home и карты nginx (`lists.py`). Домен, который DNS
   ведёт на сервер, а nginx не пропускает, — тихо мёртвый сайт. Сторож — `test_proxy_list_same_in_dns_and_nginx`.
3. В `map … { hostnames; }` у nginx `.домен` уже покрывает голый домен. Строка с голым доменом рядом —
   «conflicting parameter», и nginx не стартует. Значит, 443 лёг у всех.
4. `127.0.0.1` (и любой loopback) никогда не попадает в `allowed_clients`: весь DoH приходит от nginx с
   loopback, и такая строка открыла бы DNS всем. Пустой `allowed_clients` тоже значит «пускать всех»,
   поэтому там всегда есть самопроверка.
5. Лимита запросов по IP нет (`ratelimit: 0`): под VPN все пользователи ноды приходят с одного IP выхода.
   Доступ держится на ClientID, а не на лимите.
6. `resolver` в nginx — публичный (1.1.1.1), не наш AdGuard: тот вернёт на домен из прокси наш же IP,
   и nginx зациклится сам на себя.
7. `$dnsrewrite=<IPv4>` отдаёт A = IP сервера и пустые AAAA/HTTPS — так и нужно. AAAA увёл бы телефон
   мимо прокси, а HTTPS-запись дала бы ECH и чужой внешний SNI.
8. Правила AdGuard Home перечитывает в фоне 1–2 с после `set_rules`: проверка сразу после `apply` видит
   старое. `selfcheck` повторяет попытки.
9. Строгий Частный DNS Android + VPN под белыми списками = VPN не поднимется (адрес сервера резолвить
   нечем). С VPN — DoH в «удалённый DNS» VPN-приложения (`clients.howto`).
10. Мастер первого запуска AdGuard Home — только на 127.0.0.1 (`--web-addr`): на внешнем адресе сервер
    настроил бы первый, кто зайдёт. Порт 3000 в `install/configure` тот же, что у мастера, — так можно.

# Nexus DNS

Свой DNS-сервер на VPS. Делает две вещи:

1. **Режет рекламу**, в первую очередь в мобильных играх: AdMob, Unity Ads, AppLovin,
   ironSource, Mintegral, Pangle, Яндекс и другие рекламные сети. Заодно режет рекламу и
   слежку самих телефонов (Realme/OPPO, Xiaomi, Samsung, Huawei).
2. **Открывает Gemini, ChatGPT, Claude и другие ИИ из РФ** без VPN. DNS отдаёт на их домены
   IP сервера, сервер пропускает соединение к настоящему сайту, и сайт видит зарубежный IP.

У каждого устройства свой секретный адрес и свой профиль: «семья» или «ребёнок»
(ребёнку дополнительно закрыты взрослые сайты и включён безопасный поиск). Посторонний
без адреса получает отказ.

```
телефон ──DoT :853 / DoH :443──► nginx (смотрит SNI, не расшифровывает)
                                   ├─ dns.домен, *.dns.домен ─► AdGuard Home (блок-листы, профили)
                                   ├─ домены из lists/proxy.txt ─► настоящий сайт (Gemini…)
                                   └─ всё остальное ─► сброс (это не открытый прокси)
```

Внутри — [AdGuard Home](https://github.com/AdguardTeam/AdGuardHome) и nginx. Утилита
`nexus-dns` (Python, только stdlib) приводит их в нужное состояние по файлам из `lists/`.

## Что нужно

- **VPS за границей** в стране, где работает Gemini (Европа, США, Великобритания…). Хватит
  1 ядра и 1 ГБ. **Не на ноде Nexus:** там 443 занят Reality, а шлюзу DNS нужен весь 443.
  После аренды проверь, что IP пингуется из дома без VPN: заблокированный IP не спасти.
- **Домен в Cloudflare** (можно поддомен существующего): `dns.example.com`.
- **Токен Cloudflare** (My Profile → API Tokens → Create Token → «Edit zone DNS»;
  права Zone.DNS Edit + Zone.Zone Read на эту зону). Нужен для сертификата на
  `*.dns.example.com` и записей DNS: установщик создаст их сам, с серым облаком.

## Установка

```bash
git clone https://github.com/Rklm-it/nexus-dns /opt/nexus-dns
sudo /opt/nexus-dns/install.sh
```

Установщик спросит домен, токен и почту, а потом сделает всё сам:
- поставит пакеты и файрвол;
- создаст записи в Cloudflare;
- выпустит сертификат;
- поднимет AdGuard Home и nginx;
- применит списки и проверит сервер снаружи.

Повторный запуск — обновление, настройки он помнит (`/etc/nexus-dns/nexus-dns.env`).

## Устройства

```bash
nexus-dns client add "Сын" --profile kids
nexus-dns client add "Папа телефон"          # профиль family
nexus-dns client list
nexus-dns client show "Сын"                  # адрес и инструкция ещё раз
nexus-dns client rm "Сын"                    # его адрес перестаёт работать сразу
```

`client add` печатает адрес и инструкцию для этого устройства.

| Где | Что вписать |
|---|---|
| Android 9+ без VPN | Настройки → Подключение и общий доступ → **Частный DNS** → Имя хоста: `<id>.dns.example.com` |
| iPhone, браузер, Windows 11 | DoH: `https://dns.example.com/dns-query/<id>` |
| Роутер (OpenWrt, Keenetic, AdGuard Home…) | DoT `tls://<id>.dns.example.com` или DoH-ссылка |
| VPN-приложение (v2rayNG, Hiddify, Happ…) | DoH-ссылка в поле «Удалённый DNS» / Remote DNS |

## VPN и белые списки

| Ситуация | Как подключать | Работает? |
|---|---|---|
| Wi-Fi или мобильный без белых списков, VPN выключен | Частный DNS (DoT) | да |
| **Любой VPN включён**, в том числе для обхода белых списков | DoH-ссылка в «Удалённый DNS» VPN-приложения, Частный DNS — «Автоматически» | да: DNS идёт внутри туннеля и доходит до сервера при белых списках |
| Белые списки, VPN выключен | — | нет: оператор не пускает к зарубежному серверу. С Частным DNS Android покажет «нет интернета», переключи на «Автоматически» |
| Дома, все устройства сразу | DNS на роутере | да, на телефонах ничего настраивать не надо |

Почему при VPN не строгий Частный DNS: VPN-приложение само резолвит адрес своего сервера
через системный DNS. При строгом Частном DNS под белыми списками наш сервер до поднятия
туннеля недоступен, и VPN с доменом в адресе сервера не подключится. В «Удалённом DNS»
запросы идут уже по туннелю, а адрес сервера VPN находит обычным DNS сети.

Лимита запросов по IP на сервере нет: под VPN все пользователи ноды приходят с одного IP
выхода. Чужих отсекает секретный адрес устройства.

## Реклама в играх: чего ждать

- Межстраничная реклама и баннеры из рекламных сетей исчезают: игра пробует показать,
  не получает ответа и идёт дальше.
- **Бонус за просмотр рекламы** («посмотри ролик — получи монеты») без рекламы не выдаётся.
  Это не поломка.
- Редкие игры показывают рекламу со своих же серверов. Такую DNS от самой игры не отличит.
- Если игра или приложение сломалось: открой панель → Журнал запросов, найди красные строки
  этого устройства, впиши домен в `lists/allow.txt` и выполни `nexus-dns apply`.

## ИИ через прокси

`lists/proxy.txt` — домены, которые идут через сервер (Gemini, AI Studio, NotebookLM,
ChatGPT, Claude, Copilot, Grok). Строка покрывает домен со всеми поддоменами.

- Работает для того, что **сам сайт** не пускает из РФ. **Не помогает** против блокировок
  ТСПУ (YouTube, Instagram): прокси не шифрует. Такие домены `nexus-dns` в список не пустит.
- Сайт открылся не полностью — смотри в журнале, к каким ещё доменам он ходит, и добавь их.
- ChatGPT стоит за Cloudflare. На IP дата-центра Cloudflare иногда показывает проверку
  «вы человек?» — браузер её проходит.
- Для этих доменов DNS отдаёт только IPv4 и пустые AAAA/HTTPS. Иначе телефон ушёл бы по
  IPv6 мимо прокси или включил ECH, и шлюз не увидел бы имя сайта.

## Панель

`https://dns.example.com/` — AdGuard Home: журнал запросов (сутки), статистика (неделя),
устройства. Логин и пароль показывает установщик, они же лежат в
`/etc/nexus-dns/nexus-dns.env`. Устройства и списки удобнее менять через `nexus-dns`:
`apply` перезаписывает только свой блок правил и свои списки «nexus:», правила,
добавленные руками в панели, не трогает.

## Что открыто снаружи

| Порт | Что |
|---|---|
| 443/tcp | nginx: DoH и панель для `dns.домен`, прокси для доменов из списка, остальное — сброс |
| 853/tcp, 853/udp | DoT и DoQ AdGuard Home |
| 53, 5300, 3000, 8443 | закрыты файрволом (своя таблица nftables, SSH и чужие правила не трогает) |
| 443/udp | отказ: браузер сразу уходит с QUIC на TCP |

Открытого DNS на 53 нет: такой сервер используют для DDoS-атак, и хостер за это банит.

## Обслуживание

```bash
nexus-dns status        # проверка снаружи: DoH, DoT, прокси, реклама, отказ чужим, сертификат
nexus-dns apply         # после правки lists/
cd /opt/nexus-dns && git pull && ./install.sh                 # обновить всё
AGH_UPGRADE=1 ./install.sh                                    # + новая версия AdGuard Home
```

Сертификат продлевает certbot сам, после продления AdGuard Home перезапускается.
